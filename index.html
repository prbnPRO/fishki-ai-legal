Fishki AI Scheduler

Личный инструмент для планирования публикаций видео на YouTube-канале и TikTok-аккаунте @fishki_ii рубрики «Фишки ИИ». Приложение используется владельцем каналов для загрузки собственных видео и назначения даты их публикации через официальные API YouTube и TikTok.
