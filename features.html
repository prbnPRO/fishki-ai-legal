features

What it actually does

Everything below runs against a small local queue file and two official publishing APIs — there is no dashboard to log into and no data sent anywhere beyond the platforms the video is being posted to.

Caption & hashtag generation

Each video already has a short script attached to it (the narration used in the video itself). That script is passed to an AI model with instructions to write one short, platform-appropriate hook sentence, then paired with a small fixed set of relevant hashtags — never more than five, matching current short-form platform norms rather than the old spray-and-pray hashtag lists.

Dual-platform queue

A single JSON queue file tracks every upcoming video: its id, the platform it targets, the generated caption, the scheduled date and time, and whether it has already been posted. TikTok and YouTube entries are scheduled on separate cadences so the same content doesn't land on both platforms on the exact same day.

  • Automatic date assignment on a fixed weekly cadence
  • Per-platform status tracking (scheduled / posted)
  • Simple command-line commands to check what's next and mark items as posted

Publishing via official APIs

Uploads go through the TikTok Content Posting API and the YouTube Data API v3, authenticated with OAuth using credentials that belong to the same account that owns the channels. Nothing is posted to any account other than the one that authorized the app.

Scope of access

The tool only requests permission to upload and manage videos on the authorizing account's own channels. It does not read messages, contacts, or any personal data unrelated to publishing the creator's own videos.
