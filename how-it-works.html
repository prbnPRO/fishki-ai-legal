how it works

From finished video to scheduled post

Five steps, run once per batch of videos. No step requires logging into TikTok or YouTube by hand.

01

Add a finished video to the queue

A finished, edited vertical video file (with its accompanying short script) is placed in the local video folder that the tool watches.

02

Generate the caption

The tool sends the video's script to an AI model and receives back a short caption sentence plus a small set of relevant hashtags.

03

Assign a publish date

The video is slotted into the next open date on a fixed weekly cadence, separately for TikTok and for YouTube Shorts, and written into the local queue file (publish-schedule.json).

04

Publish through the official API

On the scheduled date, the video, caption, and hashtags are submitted through the TikTok Content Posting API or the YouTube Data API v3, using an OAuth token that was authorized once by the channel owner.

05

Mark it posted

The queue entry is updated to reflect that the video has been published, so the next run of the tool knows what's left to do.

What this tool does not do

It does not generate video content, does not access any account other than the one that explicitly authorized it, and does not run continuously in the background — each step is triggered manually by the person operating it.
